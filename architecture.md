# Architecture of the Platform / Архитектура платформы

## Core / Ядро

**Platform = Social Network + Education + AI Layer + Collaborative Projects**  
**Платформа = Социальная сеть + Образование + ИИ-слой + Совместные проекты**

---

## 1. Security & Authentication / Безопасность и аутентификация

- Authentication is implemented via **low-code**.
- The device confirms the user's identity based on predefined reliable parameters (saved biometrics or another robust factor).
- Principle: the person understands at every moment what the system is doing.
- Minimum of entities: no complex chains of API keys and tokens that create noise and points of failure.
- Security is built into the architecture (1:1), not added as an overlay.

- Аутентификация реализуется через **низкий код**.
- Устройство подтверждает личность пользователя по заранее определённым надёжным параметрам (сохранённая биометрия или другой устойчивый фактор).
- Принцип: человек в каждый момент понимает, что делает система.
- Минимум сущностей: никаких сложных цепочек API-ключей и токенов, которые создают шум и точки отказа.
- Безопасность встроена в архитектуру (1:1), а не является надстройкой.

## 2. Educational Program / Образовательная программа

- There is a paid and a free version.
- **The content is identical**.
- The only difference is the access condition: for some users the program is free.
- No artificial limitation of functionality in the free version.

- Существует платная и бесплатная версия.
- **Содержание одинаковое**.
- Разница только в условии доступа: для части пользователей программа бесплатна.
- Никакого искусственного ограничения функционала бесплатной версии.

## 3. AI Layer / ИИ-слой

- A full AI layer inside the platform.
- Ability to connect various AI agents.
- **Co-authorship with AI** mode — human and model work on the same material or project.
- AI is used as an enhancement tool, not as a replacement for the human.

- Полноценный ИИ-слой внутри платформы.
- Возможность подключения различных ИИ-агентов.
- Режим **соавторства с ИИ** — человек и модель работают над одним материалом или проектом.
- ИИ используется как инструмент усиления, а не как замена человека.

## 4. Activity Logic / Логика активностей

- The activity program is built **from the bottom up**.
- The user starts with basic actions and gradually moves to more complex and valuable ones.
- The order of activities has internal logic and guides user movement (not chaotic).

- Программа активностей построена **снизу вверх**.
- Пользователь начинает с базовых действий и постепенно переходит к более сложным и ценным.
- Порядок активностей имеет внутреннюю логику и направляет движение пользователей (не хаотичный).

## 5. Collaborative Projects / Совместные проекты

- Users can create and run projects together.
- Support for teamwork.
- Integration with the AI layer (co-authorship, agent assistance).

- Пользователи могут создавать и вести проекты вместе.
- Поддержка командной работы.
- Интеграция с ИИ-слоем (соавторство, помощь агентов).

## 6. Monetization & Widgets / Монетизация и виджеты

- Ability to embed widgets (offers, promo codes, activities, etc.) on your own terms.
- The platform controls the placement rules, not external services.

- Возможность встраивать виджеты (офферы, промокоды, активности и т.д.) на своих условиях.
- Платформа контролирует правила размещения, а не внешние сервисы.

## Core Principles / Основные принципы

- Transparency and clarity for the user.
- Security as a property of the design, not as a separate module.
- Simplicity of the interface.
- 1:1 correspondence between what is declared and what is implemented.
- Openness where it strengthens the system, and strict control where it concerns user access and data.

- Прозрачность и понятность для пользователя.
- Безопасность как свойство конструкции, а не как отдельный модуль.
- Простота интерфейса.
- 1:1 соответствие заявленного и реализованного.
- Открытость там, где это усиливает систему, и жёсткий контроль там, где речь идёт о доступе и данных пользователя.
